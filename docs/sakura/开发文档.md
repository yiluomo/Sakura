# 开发文档

## 开发目标

构建可扩展的对话生命系统，支持人格、记忆、情绪和多模态表现。

## 开发阶段

| 阶段 | 目标 | 状态 |
|------|------|------|
| Phase 0 | 世界骨架 | ✅ 完成 |
| Phase 1 | 对话系统 | ✅ 完成 |
| Phase 2 | 记忆系统 | 🚧 进行中 |
| Phase 3 | 表现层 | 📋 计划中 |
| Phase 4 | 多模态 | 📋 计划中 |

## Phase 0: 世界骨架 ✅

- [x] 项目结构搭建
- [x] API 层基础接口
- [x] Core 层对话调度
- [x] Mock 模型测试

## Phase 1: 对话系统 ✅

- [x] 接入 DeepSeek API
- [x] 接入 Ollama (备用)
- [x] 短期记忆（MySQL 数据库持久化）
- [x] 长期记忆（数据库索引 + Markdown 文件双轨存储）
- [x] 长期记忆 LLM 关键词提取（5~10个，用于检索）
- [x] 用户状态追踪（亲密度、情绪、统计）
- [x] 基础人格系统
- [x] 提示词构建
- [x] 对话测试脚本
- [x] 记忆去重机制
- [x] 数据库异步操作
- [x] 短期记忆自动压缩归档（LLM摘要 → 长期记忆）
- [x] 配置文件支持环境变量覆盖（DATABASE_URL / MEMORY_STORE_DIR）
- [x] Docker 容器化部署支持
