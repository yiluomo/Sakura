# 开发文档

## 开发目标

构建可扩展的对话生命系统，支持人格、记忆、情绪和多模态表现。

## 开发阶段

| 阶段 | 目标 | 状态 |
|------|------|------|
| Phase 0 | 世界骨架 | ✅ 完成 |
| Phase 1 | 对话系统 | ✅ 完成 |
| Phase 2 | 记忆系统 | 🚧 进行中 |
| Phase 3 | 表现层 | 📋 计划中 |
| Phase 4 | 多模态 | 📋 计划中 |

- [x] 项目结构搭建

- [x] 接入 DeepSeek API
- [x] 接入 Ollama (备用)

- [x] 长期记忆 LLM 关键词提取（5~10个）
- [x] 用户状态追踪（亲密度、情绪、统计）
- [x] 基础人格系统
- [x] 提示词构建（注入长期记忆内容）

- [x] 记忆去重机制（按 memory_type + key 唯一定位）
- [x] 数据库异步操作
- [x] 短期记忆自动压缩归档（LLM 摘要 → `summaries.md`）
- [x] 手动触发短期记忆归档（前端"归档记忆"按钮）
- [x] 配置文件支持环境变量覆盖

## Phase 2: 记忆系统 🚧

### 已完成
- [x] 长期记忆文件化存储（`memory_store/*.md`，人类可读可编辑）
- [x] LLM 自动提取记忆关键词（5~10个）
- [x] 数据库作为轻量索引（存 keywords / file_path，不存完整内容）
- [x] 对话压缩自动归档到 `summaries.md`
- [x] 手动强制归档（`force_archive`，无视阈值限制）
- [x] 安全迁移脚本（`migrate_db.py`，迁移前先备份旧数据到文件）
