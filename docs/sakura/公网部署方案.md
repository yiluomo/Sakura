# 公网访问部署方案

> 本文档记录在后端暴露公网时的安全加固方案，供日后实施参考。
> 当前已完成：静态 Token 认证（`X-API-Token` 请求头）。

---

## 当前状态（已完成）

```
手机 App / 桌面 App
  │  请求头携带 X-API-Token
  ▼
后端 FastAPI（局域网）
  └─ api/deps.py  verify_token()  →  Token 不匹配返回 401
```

**优点**：实现简单，零额外依赖，满足局域网私用场景。  
**限制**：Token 明文传输（HTTP），不适合公网直接暴露。

---

## 目标架构（待实施）

```
手机 App（外网）
  │  HTTPS 加密
  ▼
Cloudflare 边缘节点（免费 CDN + SSL）
  │  加密隧道（TLS 1.3）
  ▼
家用电脑 cloudflared 进程
  │  本地转发
  ▼
后端 FastAPI :8000
  └─ X-API-Token 认证 + 请求频率限制
```

## 实施步骤

### Step 1：更换更强的 Token（5 分钟）

当前 Token 是示例值，暴露公网前必须换成足够随机的字符串：

```python
# 生成强 Token（在 Python 环境中运行）
import secrets
print(secrets.token_urlsafe(32))
# 示例：K7mP9vZqR3nHsT2wLd6YjAeGcBfUoWi4xNp1E8sCk0
```

**同步修改两处**（保持一致）：

1. `backend/src/config.py`：
   ```python
   API_TOKEN = os.environ.get("API_TOKEN", "你生成的新Token")
   ```

2. `frontend/src/api/index.ts`：
   ```typescript
   const API_TOKEN = '你生成的新Token'
   ```

---

### Step 2：配置 Cloudflare Tunnel（30 分钟）

Cloudflare Tunnel 提供免费的 HTTPS 内网穿透，**不需要公网 IP**，不需要自己配 SSL 证书。

#### 2.1 注册 Cloudflare 账号

前往 [cloudflare.com](https://cloudflare.com) 注册，并添加一个域名（可使用免费域名）。

#### 2.2 安装 cloudflared

```powershell
# Windows 下载
winget install --id Cloudflare.cloudflared

# 或手动下载 exe：
# https://github.com/cloudflare/cloudflared/releases/latest
```

#### 2.3 登录并创建 Tunnel

```powershell
# 登录（会打开浏览器授权）
cloudflared tunnel login

# 创建 Tunnel（名称自定义）
cloudflared tunnel create sakura-backend

# 查看 Tunnel ID（记录备用）
cloudflared tunnel list
```

#### 2.4 配置路由

创建配置文件 `~/.cloudflared/config.yml`：

```yaml
tunnel: <你的 Tunnel ID>
credentials-file: C:\Users\<用户名>\.cloudflared\<Tunnel ID>.json

ingress:
  - hostname: api.你的域名.com   # 替换为你的子域名
    service: http://localhost:8000
  - service: http_status:404
```

#### 2.5 绑定域名 DNS

```powershell
cloudflared tunnel route dns sakura-backend api.你的域名.com
```

#### 2.6 启动 Tunnel

```powershell
# 临时启动（测试）
cloudflared tunnel run sakura-backend

# 安装为 Windows 服务（开机自启）
cloudflared service install
```

#### 2.7 修改前端 API 地址

```typescript
// frontend/src/api/index.ts 或 .env 文件
baseURL: 'https://api.你的域名.com/api'
```

---

### Step 3：加请求频率限制（20 分钟）

防止接口被暴力调用消耗 LLM API 额度：

#### 安装依赖

```bash
pip install slowapi
```

#### 修改 `backend/src/main.py`

```python
from slowapi import Limiter, _rate_limit_exceeded_handler
from slowapi.util import get_remote_address
from slowapi.errors import RateLimitExceeded

limiter = Limiter(key_func=get_remote_address)
app.state.limiter = limiter
app.add_exception_handler(RateLimitExceeded, _rate_limit_exceeded_handler)
```

#### 在 chat 接口添加限速

```python
# api/chat.py
from slowapi import Limiter
from slowapi.util import get_remote_address
from fastapi import Request

limiter = Limiter(key_func=get_remote_address)

@router.post("/chat")
@limiter.limit("20/minute")   # 每 IP 每分钟最多 20 次
async def chat(request: Request, req: ChatRequest):
    ...
```

## 安全评估

| 威胁 | 不做公网 | 静态 Token + HTTP 公网 | 静态 Token + Cloudflare HTTPS | + 频率限制 |
|------|---------|----------------------|------------------------------|-----------|
| 未授权访问 | ✅ 无风险 | ✅ Token 保护 | ✅ Token 保护 | ✅ |
| Token 被嗅探 | ✅ 无风险 | ❌ 明文传输 | ✅ HTTPS 加密 | ✅ |
| 暴力枚举 Token | ✅ 无风险 | ⚠️ 理论可能 | ✅ 强 Token 足够安全 | ✅ |
| LLM API 被刷 | ✅ 无风险 | ❌ 无限制 | ⚠️ 需额外限速 | ✅ |
| DDoS | ✅ 无风险 | ❌ 裸露 | ✅ Cloudflare 防护 | ✅ |

**结论**：Step1（换强 Token）+ Step2（Cloudflare Tunnel）是最高优先级，Step3（频率限制）可选但推荐。

---

## 不采用 JWT 动态 Token 的理由

动态 JWT 方案（access_token + refresh_token）解决的问题是：
> *Token 泄露后，如何把损失限制在有效期窗口内？*

在本项目中：
- 用户只有你一人，无需多用户隔离
- HTTPS 传输已防止 Token 被嗅探
- 静态强 Token + HTTPS 的安全性已远超需求

JWT 方案需要额外增加约 **200 行代码**（登录接口、JWT 签发、刷新逻辑、Token 存储），且带来前端并发刷新的竞态问题，**不值得引入**。
