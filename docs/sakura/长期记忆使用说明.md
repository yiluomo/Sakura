# 长期记忆功能使用说明

## 功能概述

长期记忆系统支持智能关键词检测和分类保存。当用户输入"记住"开头的消息时：
1. **八重樱会正常回复**（不受影响）
2. **同时弹窗确认**是否保存为长期记忆
3. **记忆保存是后台操作**，不会打断对话流程

## 使用方式

### 1. 基本语法

```
记住 + 内容
```

### 2. 支持的记忆类型

系统会自动检测以下关键词并分类保存：

| 记忆类型 | 关键词 | 重要度 | 示例 |
|---------|--------|--------|------|
| 姓名 (name) | 我叫、我的名字、叫我、我是 | 5 | "记住我叫依洛沐" |
| 爱好 (hobby) | 我喜欢、我爱、我的爱好、我喜爱 | 4 | "记住我喜欢看书" |
| 厌恶 (dislike) | 我讨厌、我不喜欢、我厌恶 | 4 | "记住我不喜欢辣的" |
| 家人 (family) | 我的家人、我的父母、我的爸爸、我的妈妈 | 5 | "记住我的妈妈是老师" |
| 朋友 (friend) | 我的朋友、我的好友 | 4 | "记住我的朋友叫小明" |
| 生日 (birthday) | 我的生日、我生日、我出生 | 5 | "记住我的生日是3月15日" |
| 年龄 (age) | 我今年、我的年龄、我多大 | 4 | "记住我今年25岁" |
| 居住地 (location) | 我住在、我来自、我在、我的家乡 | 4 | "记住我住在北京" |
| 职业 (occupation) | 我的工作、我是、我做、我的职业 | 4 | "记住我的工作是程序员" |
| 经历 (experience) | 我曾经、我以前、我经历过 | 3 | "记住我曾经去过日本" |

### 3. 使用示例

#### 示例1：保存新记忆

**用户输入：**
```
记住我叫依洛沐
```

**系统响应：**
1. **八重樱正常回复**（例如："好的，依洛沐。"）
2. **同时弹出确认对话框**：
   ```
   标题：保存记忆
   内容：检测到【姓名】信息，是否保存？
         内容：我叫依洛沐
   按钮：[保存] [取消]
   ```

**用户点击"保存"后：**
- 显示成功提示："记忆已保存"
- 对话继续，不影响八重樱的回复

#### 示例2：更新已存在的记忆

**用户输入：**
```
记住我叫伊洛沐
```

**系统响应：**
1. **八重樱正常回复**
2. **同时弹出确认对话框**：
   ```
   标题：更新记忆
   内容：检测到【姓名】信息，是否更新？
         旧值：我叫依洛沐
         新值：我叫伊洛沐
   按钮：[更新] [取消]
   ```

**用户点击"更新"后：**
- 显示成功提示："记忆已保存"

#### 示例3：取消保存

**用户点击"取消"后：**
- 显示提示："已取消保存"
- 八重樱的回复保持不变

### 4. 通用记忆

如果输入的内容不包含任何关键词，系统会将其保存为"通用记忆"：

**用户输入：**
```
记住今天天气很好
```

**系统响应：**
1. **八重樱正常回复**
2. **同时弹出确认对话框**：
   ```
   标题：保存记忆
   内容：检测到【通用记忆】信息，是否保存？
         内容：今天天气很好
   按钮：[保存] [取消]
   ```

## 核心特性

### 1. 不影响对话流程

- ✅ 八重樱始终正常回复，不会被记忆保存打断
- ✅ 记忆保存是后台操作，通过弹窗异步确认
- ✅ 用户可以边聊天边决定是否保存记忆

### 2. 智能分类

- 自动识别10种记忆类型
- 根据关键词智能分类
- 不同类型有不同的重要度

### 3. 去重机制

- 检测是否已存在相同类型的记忆
- 如果存在，提示用户是否更新
- 显示旧值和新值对比

### 4. 用户确认

- 所有记忆保存都需要用户确认
- 避免误保存不重要的信息
- 用户有完全的控制权

## 技术实现

### 后端流程

1. **正常对话**：`conversation.py` 调用LLM生成回复
2. **保存短期记忆**：将对话保存到数据库
3. **检查记忆触发**：`check_memory_trigger()` 检测"记住"关键词
4. **返回双重信息**：同时返回回复和记忆信息

### 前端流程

1. **发送消息**：用户输入"记住..."并发送
2. **显示回复**：立即显示八重樱的回复
3. **检查记忆信息**：如果有 `memory_info`，弹出确认对话框
4. **异步确认**：用户确认后调用 `/memory/confirm` API
5. **显示结果**：显示保存成功或取消的提示

### 数据库存储

记忆保存在 `long_term_memory` 表中：

```sql
CREATE TABLE long_term_memory (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id VARCHAR(50),
    memory_type VARCHAR(50),  -- 记忆类型（name, hobby, family等）
    key VARCHAR(100),         -- 关键词（"我叫"、"我喜欢"等）
    value TEXT,               -- 完整内容
    importance INT,           -- 重要度（1-5）
    created_at DATETIME,
    updated_at DATETIME
);
```

## 优势

1. **不打断对话**：记忆保存不会影响八重樱的正常回复
2. **异步确认**：用户可以在看到回复后再决定是否保存
3. **智能分类**：自动识别记忆类型，便于后续检索
4. **去重机制**：避免重复保存相同信息
5. **用户控制**：所有保存都需要用户确认

## 注意事项

1. 必须以"记住"开头才会触发记忆保存检测
2. 即使取消保存，对话仍会被记录在短期记忆中
3. 重要度越高的记忆在回忆时优先级越高
4. 同一类型的记忆会被去重，只保留最新的一条
5. 记忆保存是异步操作，不会阻塞对话流程
