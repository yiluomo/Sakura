# 更新日志

## 2026-02-03 - 长期记忆系统优化

### 新增功能

1. **智能记忆分类**
   - 自动识别10种记忆类型（姓名、爱好、家人、朋友等）
   - 根据关键词智能分类保存
   - 不同类型有不同的重要度（1-5级）

2. **记忆去重机制**
   - 检测是否已存在相同类型的记忆
   - 如果存在，提示用户是否更新
   - 显示旧值和新值对比

3. **弹窗确认机制**
   - 所有记忆保存都需要用户确认
   - 清晰显示记忆类型和内容
   - 用户可以选择保存、更新或取消

### 核心改进

**问题修复：记忆保存不再影响模型回复**

- **之前**：当用户说"记住..."时，系统会直接保存记忆并返回固定提示，模型不会生成回复
- **现在**：八重樱会正常回复，记忆保存通过弹窗异步确认，不打断对话流程

### 技术实现

#### 后端改动

1. **conversation.py**
   - 修改 `handle_message()` 函数
   - 始终调用LLM生成回复
   - 同时检查是否需要保存记忆
   - 返回双重信息：回复 + 记忆信息

2. **long_term.py**
   - 重命名 `maybe_save_long_term()` 为 `check_memory_trigger()`
   - 只检测和返回记忆信息，不直接保存
   - 新增 `_detect_memory_type()` 函数进行智能分类
   - 新增 `confirm_save_memory()` 函数处理确认保存

3. **chat.py**
   - 修改 `/chat` 接口，始终返回模型回复
   - 新增 `/memory/confirm` 接口处理记忆确认

#### 前端改动

1. **chat.ts**
   - 修改 API 接口，支持 `memory_info` 字段
   - 新增 `confirmMemory()` 方法

2. **chat.ts (store)**
   - 修改 `sendMessage()`，始终显示模型回复
   - 新增 `confirmMemory()` 方法，不添加额外消息

3. **ChatView.vue**
   - 新增 `handleMemoryConfirm()` 函数
   - 新增 `getMemoryTypeLabel()` 函数
   - 修改 `handleSendMessage()`，检查记忆信息并弹窗

### 使用示例

**用户输入：**
```
记住我叫依洛沐
```

**系统行为：**
1. 八重樱正常回复："好的，依洛沐。"
2. 同时弹出确认对话框：
   ```
   标题：保存记忆
   内容：检测到【姓名】信息，是否保存？
         内容：我叫依洛沐
   按钮：[保存] [取消]
   ```
3. 用户确认后显示："记忆已保存"

### 支持的记忆类型

| 类型 | 关键词 | 重要度 |
|------|--------|--------|
| 姓名 | 我叫、我的名字、叫我 | 5 |
| 爱好 | 我喜欢、我爱 | 4 |
| 厌恶 | 我讨厌、我不喜欢 | 4 |
| 家人 | 我的家人、我的父母 | 5 |
| 朋友 | 我的朋友、我的好友 | 4 |
| 生日 | 我的生日、我生日 | 5 |
| 年龄 | 我今年、我的年龄 | 4 |
| 居住地 | 我住在、我来自 | 4 |
| 职业 | 我的工作、我做 | 4 |
| 经历 | 我曾经、我以前 | 3 |
